# 撮影の改善事項（サイズ推定とは別に継続）

実機で頭皮の自動撮影が難しく、撮影できてもピントが合わないことがある。2026-11-14のユーザー確認を受け、未解決事項として保持する。

- 頭皮の中央ではなく髪と頭皮の境界へフォーカスする方法を検証する。
- 保存前に周囲の毛の鮮明さ・手ぶれを評価する。低解像度解析の値をそのまま解像度の異なる写真と比較しない。
- 見ずに操作できるよう、候補発見・位置合わせ・ピント調整・静止・撮影完了を音声で知らせる。
- 最短撮影距離や手ぶれが原因かを実機で切り分ける。画像だけから距離が近すぎると断定しない。
- AF成功を必須にしない現行のフォールバックは、撮影しやすさと鮮明さの両方を再検証する。

本数推定の検証には生え際を確認できる写真が必要。ぼけた写真から推定精度を主張しない。

## 解像度の分離（2026-11-15）

毛の候補識別は実機で改善を確認。元写真の解像度が次の課題というユーザー確認を受け、0.7.1では低解像度サーチと高解像度静止画の設定を分け、対応形式の保存時縮小を取り除く。白黒PNGは帯と行ごとに書き込み、全写真の出力ビットマップを持たない。高解像度でもピンぼけ・手ぶれの問題は残る。

実機で確認する項目：

- カメラ画面の撮影サイズとサーチサイズ、保存後の実ファイルのサイズを比較する。
- サーチ・ソナー・フォーカスから高解像度撮影へ進めること、非対応端末の通常モードへの再試行を確認する。
- 保存時間とメモリ使用量、連続撮影・画面回転・バックグラウンド復帰時の挙動を確認する。
- 高解像度PNGの生え際解析・拡大と中止、判定保存、以前のJPEGの読み込みを確認する。
- 領域復号に対応しない形式の取り込みでは、縮小後と元のサイズが表示されることを確認する。

## ピント合わせの変更（2026-11-15 / 0.7.2）

実機で3000×4000pxの保存を確認した一方、ぼけが残るという報告を受け、撮影直前のAF解除を修正する。地肌の中央から髪との境界へAF位置を移し、固定を保って高解像度撮影を行う。手動もAFと細部の確認を通し、タップ指定と明示的な確認省略を追加する。固定時間で失敗のまま自動撮影する処理は取り除く。

実機で継続する項目：

- 青い丸が地肌の中央や手前の指ではなく、髪と地肌の境界へ来るか確認する。
- 合わせた後の保存写真で周辺の毛が鮮明になるか確認する。距離を少し変えた場合・明るい場所・手を固定した場合を比較し、最短撮影距離と手ぶれを切り分ける。
- 条件を厳しくしすぎて撮影できなくなっていないか、手動・タップ・確認省略も試す。
- ソナー・静止と距離の音声案内、画面を離れた際の停止を確認する。
- 撮影完了までのAF固定と、撮影失敗・画面回転・バックグラウンド移動時の解除を確認する。

低解像度の局所指標とAF結果の自動テストは通せても、実機でのレンズ制御や保存画像の鮮明さは未確認。今回の変更でピント問題が解決済みとは扱わない。

## 画面を見ずに撮る前提への変更（2026-11-15 / 0.7.3）

「見ないで撮影するのでピントが合わない」という追加確認を受け、画面の青い丸・タップを主な案内にしない。開始後の準備時間、発見・消失・角度・静止・距離・保存完了の音声と、完了の3回振動を追加する。鮮明さの確認後も短く静止を待ち、映像がぼける・止まる・候補が動く場合は撮影を待ち直す。自動撮影中は画面向きを固定する。

実機で継続する項目：

- 開始ボタンを押した後、画面を見ずに声・ソナー・振動だけで位置合わせから保存まで進められるか確認する。
- 手元から頭の後ろへ構える時間、案内の聞きやすさ、読み上げとソナーの重なり、ピント待ちの長さを確認する。
- ぼけや手ぶれが残る場合、少し離して止める案内で撮影条件を改善できるか確認する。画像だけで距離の過近を断定しない。
- 音声と振動による保存完了が、保存に成功したときだけ出ることを確認する。画面を離れた後に古い案内が鳴らないことも確認する。
- 端末の向きを変えても撮影が途切れず、一覧へ戻った後に向きの固定が解除されることを確認する。

画面を見ない実撮影と音声・振動の実機確認は未完了。今回も光学的なピント問題が解決済みとは扱わない。
