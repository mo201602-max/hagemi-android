# 十円ハゲみちゃん 0.3.0 ソナー・自動撮影試作

`hagemi-0.3.0-alpha.1.apk` をダウンロードし、既存アプリを削除せず更新してください。前の版と署名・保存形式は同じです。

撮影画面で「ソナー音・自動撮影」をONにしてください。メディア音量を上げると、候補が中央へ近づくほど速くなる音が聞こえます。中央付近で約1.6秒安定するとピントを確認し、成功したら1枚撮影・保存して一覧へ戻ります。

候補の消失や動き、フレームの途切れで安定待ちをリセットします。スイッチOFF、一覧への移動、バックグラウンド化で音・自動撮影を解除します。手動撮影も使えます。ピントが合わない場合は中央で止め直すか、手動撮影してください。

検出枠は候補です。反射や背景などを誤検出する場合があります。音の速さ、中央での自動撮影、候補を外したときの待機解除、ホーム画面へ移動したときの停止を実機で確認してください。

写真とメモは端末内のみ。アプリを削除すると記録も失われます。

検証：assembleDebug、testDebugUnitTest（11件）、lintDebug成功。以前の版との署名一致を確認。実機の音・ピント・自動撮影は未確認です。
