# 十円ハゲみちゃん 0.6.0 境界間隔と三角格子の試作

既存アプリを削除せずAPKで更新してください。同じ署名・既存記録を使います。

1. 保存写真→サイズ推定を開き、黄色い楕円が脱毛範囲に合うよう調整します。
2. 「境界の間隔と三角格子を解析」を押します。比較範囲とは独立に周囲を再解析します。
3. 境界帯の緑の点と、他の紫の候補を確認します。近傍距離の分布と基準間隔を表示します。
4. 基準間隔の三角格子を重ね、均一配置を仮定した参考換算量を表示します。
5. 必要な場合だけ「格子換算を記録に採用」→保存してください。

候補不足・偏り・距離分布のばらつき・検出上限では換算を見送って理由を表示します。1500点相当を超える格子の描画は省略します。候補点と距離分布は再解析し、保存するのは範囲・基準間隔・集計点数です。

基準間隔は近傍距離の最頻区間に属する距離の中央値です。格子は検出点そのものの三角形分割ではなく、基準間隔による均一配置の見本です。内部の密度は境界に沿う間隔だけでは決まらず、実際の抜けた本数を示しません。誤検出・頭の曲面・撮影角度の影響は残ります。

検証：assembleDebug、testDebugUnitTest（31件）、lintDebug成功。以前の版との署名一致を確認。実写での精度・再現性・UI操作と保存はこれから確認します。
