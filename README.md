# 十円ハゲみちゃん 0.5.0 自動解析の試作

既存アプリを削除せずAPKで更新してください。同じ署名で、以前の写真・メモ・範囲記録を引き続き使えます。

1. 保存写真→サイズ推定→「脱毛範囲と周囲を自動提案」を押します。
2. 黄色い楕円と水色の比較範囲を確認してください。合わなければ手で囲み直せます。
3. 「選んだ比較範囲を自動カウント」で、その範囲を解析します。
4. 紫の丸が生え際に付いているか確認し、「比較範囲の二値化を表示」で処理結果を見られます。
5. 候補を使う場合だけ「点を確認して候補数を仮入力」を押します。保存後も「候補密度」の参考換算として表示し、確定本数と区別します。

自動提案できない写真では範囲を手で指定して解析できます。暗い髪で覆われた比較範囲や候補ゼロ・上限到達では仮入力できません。点が毛の交差・影・肌の模様を数えることや、つながった生え際を1つに数えることがあります。実写真での精度は未検証です。

解析は端末内・別スレッドで長辺768px以下の画像を使います。候補点と二値化画像は一時表示です。保存するのは範囲・入力値・候補由来かどうかの区別で、元写真は変更しません。

検証：assembleDebug、testDebugUnitTest（25件）、lintDebug成功。旧版との署名一致を確認。実写真の精度・UI操作・候補由来の保存と再表示はこれから実機で確認します。
