# 十円ハゲみちゃん 0.3.1 自動撮影条件の調整

APKをダウンロードして、既存アプリを削除せず更新してください。同じ署名・保存形式です。

- 白い楕円の中へ候補の中心を合わせる方式にし、中央の許容範囲を広げました。
- 安定待ちを約1秒にし、髪の重なりによる候補枠の揺れ・面積の変化を許容します。
- 安定待ちの進捗とピント調整中の表示を追加しました。
- ピントを調整し、成功通知がなくても最大1.4秒待った後に候補位置を再確認して撮影します。実写で写真の鮮明さを確認してください。
- 候補が消える、ガイド外へ移動する、画面を離れる場合は撮影を解除します。

検証：assembleDebug、testDebugUnitTest（13件）、lintDebug成功。旧版との署名一致を確認。実機の撮影成功率とピントはこれから確認します。
