# 十円ハゲみちゃん 0.7.3 見ずに撮る音声ガイド版

[APKをダウンロード](https://raw.githubusercontent.com/mo201602-max/hagemi-android/builds/0.7.3-alpha.1/hagemi-0.7.3-alpha.1.apk)

アプリを削除せず、このAPKで上書き更新してください。以前の版と署名が一致し、写真・メモ・測定値・判定を維持します。

1. メディア音量を上げ、「見ずに撮る（音・声・振動）」を押します。最初の音声案内を確認してから構えます。
2. 3秒ほど構える時間を取り、頭皮の候補を探します。見つかった・見失った・ゆっくり角度を変えるなどを声で伝えます。
3. ソナー音が速くなる位置で止まります。境界へ自動でピントを合わせ、「そのまま。撮ります」の後にも短く細部を確認してから撮影します。
4. 合わせられない場合は、少し離して止める案内が出ます。撮影できたら原寸の白黒写真を保存します。
5. 「保存できました。スマホを下ろして大丈夫です」と3回の振動が完了の合図です。保存成功後にだけ出します。

自動撮影中はプレビューのタップを無効にし、手動ボタンとメモ欄を隠します。止めるときはスイッチOFFか一覧へ戻ります。現在の画面向きを固定して端末回転で撮影画面が閉じるのを防ぎ、一覧へ戻って完了案内の時間を取った後に解除します。

音声の準備が遅れても最新の案内を保持します。音声中はソナーを抑え、画面を離れた後に古い案内を再生しません。日本語TTS・振動・音量は端末の機能と設定に依存します。音声が使えない場合は音と振動で案内します。短い振動1回は候補発見、2回は静止、3回は保存完了、長い振動は失敗です。マイクやネットワーク権限を追加せず、振動の通常権限を追加します。

「画面を見ながら撮影」では従来の手動・タップ指定も使えます。低解像度サーチと高解像度白黒保存を維持します。

検証：assembleDebug、testDebugUnitTest（97件、失敗・スキップなし）、lintDebug成功（0 errors / 21 warnings）。準備時間、案内の間隔と優先、初期化・停止後の音声キュー、静止待ち中のぼけ・映像停止・中止、手動への影響、入口表示と画面向きの解除を検証しました。画面を見ない実撮影、実機の音声・振動・合焦・手ぶれは未確認です。距離測定や光学的な最短撮影距離の補正を行う変更ではありません。
