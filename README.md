# 十円ハゲみちゃん 0.7.2 境界へのピント合わせ版

[APKをダウンロード](https://raw.githubusercontent.com/mo201602-max/hagemi-android/builds/0.7.2-alpha.1/hagemi-0.7.2-alpha.1.apk)

アプリを削除せず、このAPKで上書き更新してください。以前の版と署名が一致しています。写真・メモ・判定は端末内の既存記録を使います。

撮影直前にAFを解除していた処理を修正し、高解像度撮影の完了までピント固定を保ちます。髪と地肌の境界で模様が見える位置を選び、青い丸で表示します。手動撮影もピント合わせと細部の確認を通ります。

1. ソナー・自動撮影をONにして、黄色い候補を中央へ寄せます。
2. 青い丸の位置でピントを合わせます。そのまま動かさずに待ちます。
3. 細部を確認できれば撮影します。合わない場合は別の境界で一度試し直します。失敗のまま時間切れで自動撮影する方式をやめました。
4. 距離や明るさを変える案内が出たら、少し離す・明るい場所にするなどして試します。対応する日本語TTSがあれば音声でも案内します。

画面をタップして位置を指定することもできます。タップでは撮影せず、確認できると丸が緑になって固定します。「ピントを合わせて撮影」で記録します。合わせられない場合には「ピント確認を省略して撮影」も使えます。

低解像度サーチと原寸白黒PNG保存を維持します。以前に縮小保存した写真や保存済みのぼけを復元する変更ではありません。撮影画面と写真の詳細で実際の画素数を確認できます。

検証：assembleDebug、testDebugUnitTest（80件、失敗・スキップなし）、lintDebug成功（0 errors / 21 warnings）。撮影中のAF固定、失敗・中止・古い映像から撮影しないこと、再試行と手動の確認省略、鮮明な線・ぼかした線・平坦面・ノイズをテストしました。以前の鮮明な1枚を縮めた画像では細部を確認でき、強くぼかした派生画像では確認できない結果でした。実機のAF制御・画像の鮮明さ・撮影時間・音声は未確認です。低解像度の局所指標は試作であり、全域のピントや毛根識別精度の保証ではありません。
