# 十円ハゲみちゃん 0.2.0 コントラスト検出試作

`hagemi-0.2.0-alpha.1.apk` をダウンロードして開き、既存のアプリを削除せず更新してください。0.1.0と同じ署名・同じ保存形式です。アンインストールすると写真とメモは失われます。

- 髪と頭皮の明暗差から候補を検出して黄色い枠を表示します。
- 中央の十字と、候補の位置に合わせた案内を表示します。
- 撮影は手動です。音と自動撮影は次の段階です。
- 白黒撮影、日時・メモ付き保存、一覧・削除を引き続き利用できます。
- 明るい髪、照明の反射、分け目、背景による誤検出・未検出があります。頭皮だけでなく周りの髪も映してください。
- Android 8.0以降。写真・メモの外部送信なし。

検証：APK生成・静的チェック成功、人工画像の単体テスト6件成功、旧版との署名一致を確認。実写での検出精度・枠の位置は実機でこれから確認します。

ソース：`feat/contrast-detection` ブランチ、コミット `911c369`。
