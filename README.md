# 十円ハゲみちゃん 0.7.0 生え際候補の追跡・確認版

[APKをダウンロード](https://raw.githubusercontent.com/mo201602-max/hagemi-android/builds/0.7.0-alpha.1/hagemi-0.7.0-alpha.1.apk)

以前のアプリを削除せず、このAPKで更新してください。以前の版と署名が一致しています。アプリの削除やデータ消去は端末内の記録も削除します。

1. 「写真を取り込む」または撮影で記録し、写真→「サイズ推定」を開きます。
2. 黄色い楕円で脱毛範囲を囲み、「生え際候補を追跡して確認」を押します。
3. 全体図・拡大図と「印を表示」を切り替え、前へ・次へで候補を確認します。
4. 各点を「生え際と確認」「保留」「除外」に分け、「判定を保存」を押します。
5. 写真→「生え際の判定を見る」で保存した候補を再表示できます。

毛の暗い線を細線化・追跡し、地肌が見える境界帯の端点を候補にします。新しい候補はすべて未確認です。短い毛・先細り・重なりなどは確認用の手がかりとして示します。毛先・交差・影の誤検出もあり、候補数は脱毛本数の推定に自動反映しません。

解析は区画ごとに行い、「中止」できます。400候補の上限到達時は表示します。候補・追跡線・判定・解析範囲は端末内に保存します。以前のメモや測定値も保持します。

新規写真は長辺3000px以下、低メモリ端末では画素数を抑えて白黒保存します。写真選択は32MiB以下です。既存の低解像度・ピンぼけ画像の細部は復元できません。カメラの希望解像度は上げていますが、実際のサイズは端末に依存します。以前からのピント改善は継続課題です。

検証：assembleDebug、testDebugUnitTest（53件）、lintDebug成功（0 errors / 19 warnings）。判定・メモ・測定値の保持、再表示と画面回転、元画像の非変更、白黒化・EXIF方向を自動検証しました。画素検証にはRobolectric用の領域デコードアダプタを使用しています。同じ検証写真では確認済み16点の近くに候補を残せましたが、別写真での精度は未検証です。実機の処理時間・メモリ・UI操作・写真選択・保存は確認待ちです。

写真や検証用の座標はこのリポジトリやAPKに含めていません。アプリにネットワーク権限はありません。
