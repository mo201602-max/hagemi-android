Android用の最初の試作です。白黒で撮影し、日付・メモとともに端末内へ保存できます。

- 対象：Android 8.0以降、背面カメラ付き端末
- `app-debug.apk` をスマホへダウンロードして開くとインストールできます。Androidの確認画面が出た場合は、ダウンロード元アプリからのインストールを許可してください。
- デバッグ署名の試作版です。実機のカメラ・画面回転・再起動後の保存状態はこれから確認します。
- 写真・メモは端末のアプリ内のみ。アプリの削除・データ消去で失われます。
- ソナー、自動撮影、本数推定、キャラクター画像は今後追加します。

開発者向け：`assembleDebug` と `lintDebug` の結果はプルリクエストに記載します。
