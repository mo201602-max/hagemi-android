# 十円ハゲみちゃん 0.7.1 高解像度撮影・原寸白黒保存版

[APKをダウンロード](https://raw.githubusercontent.com/mo201602-max/hagemi-android/builds/0.7.1-alpha.1/hagemi-0.7.1-alpha.1.apk)

以前のアプリを削除せず、このAPKで上書き更新してください。同じ署名を使っています。アプリの削除やデータ消去は端末内の記録も削除します。

- サーチ用プレビューと解析映像は640×480を希望し、検出処理は長辺160px以下・毎秒最大5回を維持します。
- 静止画はCameraXが使える最大解像度・画質優先・JPEG品質100を希望します。端末によって対応サイズは異なります。
- JPEGなど領域復号に対応した写真は、画素数を保った白黒PNGとして保存します。保存時の長辺3000px制限を外しました。画像は小さな帯と行ごとに処理します。
- 写真の全体図・一覧は小さく読み、拡大は原寸の一部分を使います。高解像度の候補解析も区画ごとに行います。
- 領域復号に対応しない形式は縮小フォールバックとなり、写真の詳細に元サイズと保存サイズを表示します。PNGはJPEGよりファイルが大きくなる場合があります。

撮影画面に「撮影」と「サーチ」のサイズ、保存後の写真の詳細に「保存：幅 × 高さ px」を表示します。新しく撮った写真でサイズと生え際の鮮明さ、保存時間を確認してください。以前に縮小保存した写真の細部は復元できません。ピント改善は継続課題です。

毛の候補を確認する操作：写真→「サイズ推定」→黄色い楕円で囲む→「生え際候補を追跡して確認」。全体図・拡大図で各候補を見て「確認・保留・除外」を選び、判定を保存します。候補数の脱毛本数への換算は自動で行いません。以前のJPEG・メモ・測定値・判定を保持します。

検証：assembleDebug、testDebugUnitTest（60件）、lintDebug成功（0 errors / 21 warnings）。4032×3024の画素数と1px線、PNGの可逆復号・CRC、8種類の向き、帯の境界、高解像度PNGからの候補解析、旧形式互換を検証しました。画素検証はRobolectricの領域デコーダ用アダプタを使用し、実機のネイティブメモリ・撮影サイズ・処理時間は未確認です。

写真や検証用の個人座標はリポジトリやAPKに含めていません。アプリにネットワーク権限はありません。
