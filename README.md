# 十円ハゲみちゃん 0.4.0 範囲と周辺密度の記録

既存アプリを削除せずAPKで更新してください。署名・既存写真とメモの保存場所は以前の版と同じです。

1. 保存写真を開き「サイズ推定」を押します。
2. ①脱毛範囲を選び、写真を斜めにドラッグして黄色い楕円で囲みます。
3. ②比較範囲を選び、すぐ近くの同じ向きの頭皮を水色の四角で囲みます。黄色い枠と重ならない場所を選びます。
4. 比較範囲で生え際を確認できる毛の本数を手入力すると、楕円と四角の面積比から推定本数を表示します。
5. 保存すると写真の記録とタイムラインに反映されます。

本数を数えられない写真では空欄のまま範囲だけ保存できます。毛の自動カウントとcm²への換算は未対応です。写真内の面積割合は距離で変わるため、それだけで経過を比較できません。推定本数は頭の曲面・撮影角度・比較範囲の密度・数え方に左右されます。

写真は変更せず、範囲と入力本数を端末内のメタデータに保存します。アプリを削除すると記録は失われます。

検証：assembleDebug、testDebugUnitTest（18件）、lintDebug成功。以前の版との署名一致を確認。範囲の操作と保存・再編集は実機でこれから確認します。

ピントと見ずに撮影する案内の未解決事項はソースの docs/IMPROVEMENTS.md に保持しました。
